Educational Notes & Viva Insights

TLB Hit vs. TLB Miss

A TLB Hit translates the address in cache lookup time ($T$). A TLB Miss incurs a main-memory page-table walk ($M$) to fetch the frame number, stores it in the TLB for temporal/spatial locality, and accesses the data ($M$), totaling $T + 2M$.

Effective Access Time (EAT)

$$EAT = H \times (T + M) + (1 - H) \times (T + 2M)$$ Where $H$ is hit ratio, $T$ is TLB lookup latency (e.g. 10 ns), and $M$ is main memory latency (e.g. 100 ns). A baseline system without TLB always requires 2 memory accesses ($2M = 200\text{ ns}$).

FIFO vs. LRU Eviction

FIFO evicts the slot with the earliest insertion timestamp regardless of recent accesses. LRU updates the access timestamp on every hit and evicts the least recently referenced entry, preserving active working sets.
